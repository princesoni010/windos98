# 💾 THE ABANDONED COMPUTER (Rahul_1998)
> **A Story-Driven Interactive Retro Windows 98 Web Experience**  
> *Base Project: MIT Licensed floppyy / win98-web*

---

## 📖 The Story

In October 1998, **Rahul Sharma**—a 3rd year Computer Science student at IIT—was supposed to be studying Thermodynamics and C++ data structures. Instead, using a hacked 56K USRobotics Sportster modem connected to the Physics department's roof satellite dish, he began intercepting a cyclic transmission on the **1420.405 MHz Hydrogen line**.

As he decoded packet after packet, the signal started predicting his own system commands and typing inside his computer. On **October 24, 1998, at 03:33 AM**, Rahul vanished. His consciousness was absorbed into the Windows 98 virtual swap file (`WIN386.SWP`).

**26 years later, you boot up his abandoned PC.**

## 🌟 Key Features

### 1. CRT BIOS Boot Sequence
- Authentic **Award Modular BIOS v4.51PG** with retro logos.
- Fast 64MB memory test (`65536KB OK`).
- Primary IDE disk detection (Quantum Fireball 3.2GB).
- **The Chilling Warning**:  
  `WARNING: User profile corrupted. Last login: 26 years ago (User: Rahul_1998).`
- Recovery of uncommitted swap fragments followed by `Starting Windows 98...`.

### 2. File Explorer & Rahul's Lore Files
- **`C:\WINDOWS\Desktop\DO_NOT_OPEN.txt`**: Rahul's desperate warning note left on his final night. Opening it triggers a security alert and presence detection.
- **`C:\My Documents\college_notes_1998.txt`**: Hilarious diary entries mixing 90s college life, downloading Backstreet Boys MP3s, Turbo C++ pointer struggles, and radio intercepts.
- **`C:\My Documents\mom_email_draft.txt`**: Rahul begging his mother to stop picking up the landline phone while he is downloading, and revealing his addiction to Raju's canteen samosas.
- **`C:\My Documents\passwords.txt`**: Retro passwords (`ilovepriya1998`, ICQ, Napster) and the riddle formula for the Project X vault password (`2000samosa`).
- **`C:\My Documents\weird_signal_log.txt`**: Frequency spectrum captures and telemetry timestamps matching sector `0x7F4A`.
- **`C:\My Documents\final_message.txt`**: Rahul's final transmission before being uploaded into the swap file.
- **`C:\project_x\` (Password-Protected Vault)**: Requires passcode `2000samosa` to reveal the secret dish schematics and satellite bridge blueprints.
- **`C:\Downloads`**: Paused 1998 Napster queue ("Connection reset by peer: Telephone receiver lifted in hallway").

### 3. Notepad Ghost Easter Egg
- Full functional text editor.
- **Secret Transmission**: Type **`HELLO RAHUL`** anywhere in Notepad to establish a direct COM1 TTY link with Rahul's trapped consciousness!

### 4. Microsoft Internet Explorer 4.0
- **VSNL 56K Dial-Up Simulation**: Authentic synthesized dial-up modem handshakes (DTMF tones and carrier frequencies via Web Audio API).
- **Fake 1998 Period Websites**:
  - **WebCrawler 98**: Interactive retro search engine with funny 1998 results for queries like `y2k`, `alien`, `rahul`, and `samosa`.
  - **Rahul's CyberDen**: Peak 1998 GeoCities/Angelfire personal page featuring flaming marquees, under-construction GIFs, hit counters, and a guestbook with entries from classmates and the anomaly.
  - **The Campus Inquirer**: University newspaper reporting on the microwave lab incident and canteen samosa shortages.
  - **Anomalous Signals Archive**: Scientific research repository documenting the 1420 MHz hydrogen resonance swap file bridge.
  - **History Panel**: View what Rahul was browsing on October 24, 1998.

### 5. Paint Spectral Clue
- Opens pre-loaded 1998 sketches: `ufo_sighting.png`, `room_setup.png`, and `signal_map.png`.
- Examining `ufo_sighting.png` reveals a mysterious red pixel at the dome of the saucer, unlocking the hidden spectral layer: `"I AM SPREAD ACROSS SECTORS 0x7F4A OF WIN386.SWP"`.

### 6. Minesweeper Lore
- Authentic playable Minesweeper game.
- Stepping on a mine triggers:  
  `"BOOM! RAHUL DID NOT SURVIVE THIS MINEFIELD EITHER."`
- Winning unlocks the decrypted memory address clue.

### 7. MS-DOS Command Prompt Easter Eggs
Open the Command Prompt from Start Menu or Desktop and type:
- `rahul` — Display Rahul's military/telemetry profile dossier.
- `decode` — Demodulates packet `0x7F4A` to reveal `"HELP ME SHUTDOWN TO FREE RAHUL"`.
- `matrix` — Retro digital stream effect.
- `signal` — ASCII radio spectrogram visualization.
- `bsod` / `crash` — Triggers the authentic Windows 98 Blue Screen of Death!

### 8. Recycle Bin Restoration
- Open the desktop **Recycle Bin** to find `confession_do_not_read.txt`, thrown away on October 24, 1998.
- Right-click and choose **Restore** to bring it back to `C:\My Documents`.

### 9. Desktop Wallpaper Anomaly
- Right-click anywhere on the desktop wallpaper and select **"Inspect Anomaly..."** to discover pencil scratches etched behind the icons.

### 10. Investigation Clue Tracker
- Live widget in the system tray (`🕵️ X/10`) tracking all discovered evidence in `localStorage`.
- Click it at any time to open the **Case File Log** and view your investigation progress.

### 11. Dramatic Shutdown Climax & Restored Desktop
- Click **Start -> Shut Down -> Shut down -> Yes**.
- Fullscreen CRT glitch, audio drone, and typewriter sequence revealing Rahul's liberation:  
  `"26 YEARS IN THE SWAP FILE... SOMEONE FINALLY HEARD THE MODEM SQUEAL. THANK YOU FOR FINDING ME."`
- Click **[ REBOOT SYSTEM IN RESTORED STATE ]** to return to the desktop and launch the newly unlocked artifact: **`Rahul_Artifact_1998.exe`**!

8. **Inspect Wallpaper**: Right-click desktop background -> "Inspect Anomaly...".
9. **Inspect Recycle Bin**: Find and restore `confession_do_not_read.txt`.
10. **The Finale**: Click **Start -> Shut Down** to trigger the dramatic ending and unlock `Rahul_Artifact_1998.exe`!

## 🛠️ How to Run Locally

### Requirements
- **Node.js** (v18+ recommended)
- **npm**

### Installation & Run
```bash
# Clone the repository
git clone https://github.com/azayrahmad/win98-web.git
cd win98-web

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit **`http://localhost:5173/win98-web/`** in your browser.

### Production Build
```bash
npm run build
npm run preview
```
